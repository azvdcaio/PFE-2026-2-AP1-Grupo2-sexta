# Planejamento do Projeto

## 1. Documento 5W2H

| Diretriz | Pergunta | Descrição no Projeto |
| :--- | :--- | :--- |
| **What** | *O que será feito?* | Planejamento, design, prototipação e desenvolvimento de um portal web institucional para o Hub das empresas PKZ e One to One. |
| **Why** | *Por que será feito?* | Para unificar a identidade visual da holding e resolver a dispersão de dados, facilitando a tomada de decisão e o contato de potenciais clientes e atletas. |
| **Who** | *Quem está envolvido?* | Todos os stakeholders, ou seja, alunos envolvidos no desenvolvimento do projeto, professor, empresas e público alvo. |
| **Where** | *Onde a tarefa será realizada?* | Será planejada e realizada em sala de aula, GitHub e em meios de comunicação como o WhatsApp. |
| **When** | *Quando isso vai acontecer?* | Durante o semestre letivo. |
| **How** | *Como será feito?* | Através de tecnologias front-end (como HTML, CSS, React e JavaScript) e design estratégico com hierarquia clara, navegabilidade intuitiva por scrolling, Hero Sections e chamadas para ação (CTAs) diretas. |
| **How much**| *Quanto custará?* | O esforço e carga horária de dedicação acadêmica da equipe de alunos. |
