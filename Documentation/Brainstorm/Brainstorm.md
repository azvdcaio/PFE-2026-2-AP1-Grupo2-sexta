# Brainstorm

## Estrutura Empresarial

- Holding que reúne duas empresas do segmento esportivo
  - **PKZ Lab**
    - Treinamento esportivo infantil
    - Desenvolvimento de atletas
    - Foco em atletas de alta performance
  - **One to One**
    - Academia
    - Treinamento personalizado
    - Público de diferentes idades e objetivos

## Problemas

- Informações da empresa espalhadas em diferentes lugares
- Necessidade de melhorar a apresentação visual da marca
- Necessidade de melhorar a comunicação com os alunos
- Necessidade de apresentar melhor os serviços oferecidos

## Público

- Alunos
- Pais/responsáveis de alunos menores
- Atletas
- Professores
- Personal trainers
- Fisioterapeutas
- Nutricionistas
- Gestores da empresa
- Pessoas interessadas nos serviços
- Possíveis novos clientes

## Site

- Página inicial funcionando como Hub
- Duas opções principais:
  - PKZ Lab
  - One to One
- Ícones ou cards para escolher a empresa
- Página inicial com pouca informação para não distrair
- Frase de impacto para apresentar a proposta
- Navegação simples
- Design visual forte
- Experiência mais moderna e profissional
- Evitar excesso de informações na primeira tela
- Usar Hero Section
- Utilizar CTA para direcionar o usuário
- Possibilidade de navegação por scrolling
- Header com navegação para diferentes seções
- Página de contato
- Futuramente, login e cadastro

### PKZ Lab

## Design

- Aparência profissional
- Identidade visual coerente
- Não deixar informações "espremidas"
- Hierarquia visual clara
- Navegação intuitiva
- Hero Section chamativa
- CTA evidente
- Fotos e vídeos dos treinamentos
- Scrolling para apresentar informações
- Header fixo ou navegação entre seções
- Separar claramente PKZ e One to One
- Evitar excesso de informações no Hub
- Utilizar referências de sites modernos
- Pensar em acessibilidade
- Verificar contraste de cores
- Utilizar Figma para prototipação
