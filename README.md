## Sobre o projeto

O cliente é uma holding esportiva real, formada por duas empresas:

- **PKZ Lab** Treinamento físico voltado a atletas jovens (7 a 15 anos), com foco em performance esportiva e desenvolvimento técnico específico de cada modalidade.
- **One to One** Treinamento personalizado e condicionamento físico voltado ao público adulto (17+), com abordagem mais próxima do modelo convencional de academia.

Hoje, as informações das duas empresas estão espalhadas em diferentes canais, sem uma apresentação visual consistente. O produto proposto é um **Hub institucional único**, com uma landing page dedicada a cada marca, servindo como ponto de entrada para clientes, atletas e responsáveis conhecerem a holding e entrarem em contato, com evolução planejada para sites individuais mais completos em fases futuras do projeto.

Por se tratar de um projeto com **cliente real** dentro de uma disciplina com avaliação **rigorosa de processo**, a equipe trata prazo, escopo e tempo de trabalho como recursos reais e limitados, não apenas como formalidade de documentação acadêmica.
